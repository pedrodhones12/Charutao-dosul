# Charutão do Sul — Portal de Jornalismo, Cultura e Tecnologia

Portal editorial com identidade de jornal tradicional e experiência digital moderna, dedicado à cobertura **regional, nacional e internacional**, cultura, literatura, ciência e tecnologia.

> **Estado atual:** protótipo de interface front-end. O site demonstrativo funciona com HTML, CSS e JavaScript, com notícias editoriais de exemplo. CMS com autenticação, banco de dados e publicação real são etapas posteriores — não estão simulados como se já fossem serviços ativos.

## Objetivos
- Apurar e publicar notícias com responsabilidade, pluralidade e transparência.
- Dar visibilidade à cultura, literatura, educação, ciência e inovação.
- Organizar conteúdo por editorias, autores, tags e localização.
- Oferecer leitura acessível, rápida, responsiva e otimizada para mecanismos de busca.
- Evoluir para um CMS próprio com revisão editorial, agendamento, histórico e controle de acesso.

## Estrutura do projeto
- `index.html`: página inicial e demonstração navegável.
- `style.css`: identidade visual responsiva.
- `script.js`: menu móvel, pesquisa local demonstrativa, inscrição ilustrativa e ano do rodapé.
- `docs/ARQUITETURA.md`: arquitetura proposta e mapa do portal.
- `docs/BANCO-DE-DADOS.md`: modelo relacional inicial.
- `docs/SEGURANCA-SEO-ACESSIBILIDADE.md`: requisitos de segurança, SEO, privacidade e acessibilidade.
- `docs/PLANO-DE-IMPLEMENTACAO.md`: fases de desenvolvimento e critérios de aceite.

## Executar localmente
Abra `index.html` no navegador ou use uma extensão de servidor local, como Live Server. Não é necessário instalar dependências para visualizar o protótipo.

## Aviso editorial
As manchetes e matérias presentes no protótipo são **conteúdo demonstrativo**, não devem ser tratadas como notícias factuais. Antes de publicar conteúdo real, a redação deve verificar informações, datas, autoria, direitos de imagem e fontes.
